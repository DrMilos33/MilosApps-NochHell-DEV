# Noch hell?

Eigenständige öffentliche MilosApps-Web-App mit dem App-Key `daylight`.

Die App beantwortet an einem gewählten Ort nur: Wie lange ist es noch hell,
wann wird es wirklich dunkel und wann geht morgen die Sonne auf?

## Feste Grenzen

- kein Konto und keine App-Datenbank;
- genaue Koordinaten bleiben lokal und erscheinen nicht in Teil-URLs;
- eigener DEV-Lifecycle, Production nicht freigegeben;
- keine Shared-Abhängigkeit ohne veröffentlichten Release;
- Portal-DEV bindet nur über dokumentierte Metadaten und URL an.
